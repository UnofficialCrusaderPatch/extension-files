# Files
این افزونه به این دلیل «files» نام دارد که عملیات فایل انجام‌شده توسط بازی را رهگیری می‌کند.

ویژگی اصلی آن فراهم‌کردن روشی برای رهگیری عملیات مشخص `open` و هدایت آن‌ها به فایل‌های دلخواه است.

این افزونه موتور بسیاری از افزونه‌هایی است که به رهگیری عملیات `open` متکی هستند.

## روش استفاده
این افزونه پنج تابع ارائه می‌دهد:
```lua
--[[
عملیات open را برای یک فایل مشخص جایگزین/رهگیری می‌کند.
توجه کنید که بازی از مسیرهای سبک ویندوز استفاده می‌کند، مانند "maps\\Close Encounters.map"

file  string  مسیر اصلی مورد استفاده بازی
newfile  string  مسیر فایلی که باید جایگزین فایل اصلی شود
--]]
modules.files:overrideFileWith(file, newFile)

--[[
تابعی برای جایگزینی ثبت می‌کند که در هر بار فراخوانی عملیات open اجرا می‌شود.
برای فایل‌هایی مفید است که یک بار نه، بلکه چند بار در طول بازی بارگذاری می‌شوند.
--]]
modules.files:registerOverrideFunction(func)

--[[
توسط افزونه maploader برای تنظیم پارامترهای بارگذاری فایل‌های .amp و .sav بازی به کار می‌رود.
--]]
modules.files:setIterationOption(key, value)

--[[
مکان جایگزینی برای جست‌وجوی فایل‌های بازی تعیین می‌کند (فقط gm، gfx، fx، binks).
نقشه‌ها باید با maploader ثبت شوند.
--]]
modules.files:registerFileSource(path)

--[[
پوشه‌ای از فایل‌های .map را به فهرست نقشه‌های بازی اضافه می‌کند. مقدار `which` برابر "both" (پیش‌فرض)، "crusader" یا "extreme" است.
می‌توان چند پوشه ثبت کرد، برای نمونه یک پوشه برای هر پلاگین.
--]]
modules.files:registerExtraMapDirectory(path, which)

```

## نقشه‌هایی که از یک تاریخ به بعد ظاهر می‌شوند
یک پوشهٔ نقشهٔ اضافه می‌تواند فایل `availability.json` داشته باشد تا نقشه‌ها را فقط از تاریخ مشخصی به وقت محلی بازیکن نمایش دهد؛ مناسب برای بسته‌هایی که روزی یک نقشه باز می‌کنند. قالب آن در [README](https://github.com/UnofficialCrusaderPatch/extension-files/blob/main/README.md) آمده است.
