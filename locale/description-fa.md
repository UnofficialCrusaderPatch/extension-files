# Files

نام این افزونه «files» است، زیرا عملیات فایل بازی را دریافت و هدایت می‌کند. به‌ویژه می‌تواند فراخوانی‌های مشخص `open` را به فایل‌های انتخابی شما تغییر مسیر دهد. بنابراین پایهٔ بسیاری از افزونه‌هایی است که بازکردن فایل را تغییر می‌دهند.

## روش استفاده

افزونه چهار تابع فراهم می‌کند:

عملیات بازکردن یک فایل مشخص را جایگزین می‌کند. بازی از مسیرهای Windows مانند `maps\Close Encounters.map` استفاده می‌کند. `file` مسیر اصلی بازی و `newFile` مسیر فایل جایگزین است.

```lua
modules.files:overrideFileWith(file, newFile)
```

تابع تغییر مسیری ثبت می‌کند که با هر بار بازکردن فایل فراخوانی می‌شود. برای فایل‌هایی مفید است که به‌جای یک بار، در طول بازی بارها بارگذاری می‌شوند.

```lua
modules.files:registerOverrideFunction(func)
```

maploader از این تابع برای تنظیم پارامترهای بارگذاری فایل‌های `.map` و `.sav` بازی استفاده می‌کند.

```lua
modules.files:setIterationOption(key, value)
```

محل دیگری برای جست‌وجوی فایل‌های بازی تعیین می‌کند؛ فقط برای `gm`، `gfx`، `fx` و `binks`. نقشه‌ها باید با maploader ثبت شوند.

```lua
modules.files:registerFileSource(path)
```
