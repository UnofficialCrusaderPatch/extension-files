# Files
Это расширение называется «files», поскольку перехватывает файловые операции игры.

Ключевая возможность — перехват отдельных операций `open` для перенаправления их на нужные файлы.

Это расширение служит основой для многих других расширений, использующих перехват `open`.

## Использование
Расширение предоставляет пять функций:
```lua
--[[
Переопределяет/перехватывает операцию open для конкретного файла.
Игра использует пути в стиле Windows, например "maps\\Close Encounters.map".

file  string  исходный путь, используемый игрой
newfile  string  путь к файлу, который должен заменить исходный
--]]
modules.files:overrideFileWith(file, newFile)

--[[
Регистрирует функцию переопределения, вызываемую при каждой операции open.
Полезно для файлов, которые загружаются неоднократно в ходе игры.
--]]
modules.files:registerOverrideFunction(func)

--[[
Используется расширением maploader для настройки параметров загрузки файлов .amp и .sav.
--]]
modules.files:setIterationOption(key, value)

--[[
Задаёт альтернативный каталог для поиска файлов игры (только gm, gfx, fx, binks).
Карты следует регистрировать через maploader.
--]]
modules.files:registerFileSource(path)

--[[
Добавляет папку с файлами .map в списки карт игры. `which` — "both" (по умолчанию), "crusader" или "extreme".
Можно зарегистрировать несколько папок, например по одной на плагин.
--]]
modules.files:registerExtraMapDirectory(path, which)

```

## Карты, появляющиеся с определённой даты
Дополнительная папка карт может содержать файл `availability.json`, который показывает карты только с указанной даты по местному времени игрока — для наборов, открывающих по одной карте в день. Формат описан в [README](https://github.com/UnofficialCrusaderPatch/extension-files/blob/main/README.md).
