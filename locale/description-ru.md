# Files

Расширение называется «files», потому что перехватывает файловые операции игры. В частности, оно позволяет перенаправлять отдельные вызовы `open` на выбранные файлы. На этом основана работа многих других расширений, изменяющих открытие файлов.

## Использование

Расширение предоставляет четыре функции:

Заменяет открытие конкретного файла. Игра использует пути Windows, например `maps\Close Encounters.map`. `file` — исходный путь игры, а `newFile` — путь к заменяющему файлу.

```lua
modules.files:overrideFileWith(file, newFile)
```

Регистрирует функцию перенаправления, вызываемую при каждом открытии файла. Полезно для файлов, которые загружаются многократно по ходу игры, а не только один раз.

```lua
modules.files:registerOverrideFunction(func)
```

Используется maploader для настройки загрузки файлов `.map` и `.sav` игры.

```lua
modules.files:setIterationOption(key, value)
```

Задаёт дополнительное место поиска игровых файлов, только для `gm`, `gfx`, `fx` и `binks`. Карты следует регистрировать через maploader.

```lua
modules.files:registerFileSource(path)
```
